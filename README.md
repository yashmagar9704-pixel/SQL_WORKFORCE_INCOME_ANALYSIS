# Workforce Data Analysis using SQL

## Objective
To analyze workforce data and identify salary trends, remote work patterns, job roles, experience levels, and location-based workforce insights.

## Dataset
- Total Rows: 13,972
- Years Covered: 2020–2024
- Key Fields: Job Title, Experience Level, Salary, Location, Remote Ratio, Company Size

## KPIs Analyzed
- Average Salary by Job Title
- Salary Growth by Job Title and Experience Level
- Salary Comparison by Country
- Employee Distribution by Company Size
- Remote Work Percentage
- Fully Remote Employees Earning Over $100,000
- Salary Trends by Experience Level
- Highest and Lowest Paying Locations
- Employment Type Distribution

## Key Insights
- Analyzed salary differences across job roles, experience levels, and locations.
- Identified countries and job titles with higher salary potential.
- Compared fully remote work adoption across experience levels.
- Analyzed salary growth between different years.
- Identified locations with salaries above the overall market average.
- Developed salary-based career and domain-switching insights.

## Security
- Implemented Role-Based Access Control using SQL Server Row-Level Security.
- Restricted employee data access based on experience level.

## Tools Used
- SQL Server
- SQL Server Management Studio (SSMS)
- Excel
